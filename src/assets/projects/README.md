# Project concept artwork

Drop the generated artwork here. Each file replaces its placeholder at the next build; no code changes are needed.

| Project                | File                    |
| ---------------------- | ----------------------- |
| Tradix                 | `tradix-concept.webp`   |
| Doctori                | `doctori-concept.webp`  |
| ABRID                  | `abrid-concept.webp`    |
| Agadir Medina Showroom | `showroom-concept.webp` |
| Fundbid                | `fundbid-concept.webp`  |

- Use one aspect ratio for all five: **16:10** (for example 1600 × 1000). Images are cropped to 16:10 with `object-fit: cover`.
- `.webp`, `.png` and `.jpg` are accepted; Astro resizes them and writes responsive WebP.
- The artwork is described on the page as illustrative. Never use it for a real application screenshot.
- ABRID is a private, government-funded project: keep its artwork conceptual, with no internal screens or data.
